# Privacy

KidWhisperer Watchman is built to work with the network off.

Stored on the parent phone: display name, geofences, last GPS fix, alert titles, pairing PIN.
Never stored: microphone audio, cry spectrograms, cloud identifiers, advertising IDs.
Version 0.1.0 transmits nothing. BLE to a paired Watchman is local radio.
Do not put a child's legal name, school, or photo in this repo or in public screenshots.
